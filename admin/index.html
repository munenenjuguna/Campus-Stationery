Admin panel help
Handling orders

Open Orders. New orders are Pending. Click an order to see the items, customer and payments, then move it on: Processing (packing), Ready for Collection, then Completed when the customer has it. The system only offers the next allowed step. Cancelling an order puts its items back into stock automatically.

Payments

M-Pesa payments confirm themselves. For cash orders, completing the order records the cash as received. You can also click Record payment received and type the M-Pesa receipt from the SMS if a customer paid another way. An M-Pesa order cannot be completed until it is paid.

Reports

Open Reports and choose Sales (by day, product, category or payment method), Orders or Inventory and Stock. Set the dates and filters, choose how to sort, then click Run report. Print / Save as PDF gives a report with the shop name, logo, the date it was generated, who prepared it and the filters used. Export CSV opens in Excel.

Managing records

Pick a section on the left, for example Products. Use Add new to create a record, the pencil to edit and the bin to delete. Click a column heading to sort, and type in the search box to filter. Fields marked * are required.

Linked records

Fields that point to another table (such as a product's category) appear as dropdowns, so you can only pick values that exist.

Customer passwords

Passwords are never shown. To reset a customer's password, edit the customer and type a new one in the password field. It is hashed before it is saved.

Lists

On any list, Export CSV downloads it for Excel and Print report prints it with the shop name, logo, date, and the search and sort you applied.

Access levels

Super admin can do everything, including adding admins and resetting their passwords. Admin can manage shop data but not admin accounts.

Audit trail

Every admin and customer login, order, payment, add, edit and delete is recorded with who did it, when, and from which IP address. Use the filter to see admins or customers only.

Two factor authentication

Every admin sign in needs the password and a 6 digit code. The code is emailed, or shown in the server window when email is not set up. Under Security you can link an authenticator app (Google Authenticator, Microsoft Authenticator) instead, so the code comes from your phone. Lost phone? Choose Use an email code instead on the sign in page, or a super admin can reset your two factor setting under Admin accounts.

Forgotten admin password

A super admin can reset it under Admin accounts. If the only super admin is locked out, run npm run reset-admin in the project folder on the server computer.
