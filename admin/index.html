Admin panel help
Managing records

Pick a section on the left, for example Products. Use Add new to create a record, the pencil to edit and the bin to delete. Click a column heading to sort, and type in the search box to filter. Fields marked * are required.

Linked records

Fields that point to another table (such as a product's category) appear as dropdowns, so you can only pick values that exist.

Customer passwords

Passwords are never shown. To reset a customer's password, edit the customer and type a new one in the password field. It is hashed before it is saved.

Reports

Export CSV downloads the current list for Excel. Print report opens a printable report with the shop name, logo, date, and the search and sort you applied.

Access levels

Super admin can do everything, including adding admins and resetting their passwords. Admin can manage shop data but not admin accounts.

Audit trail

Every login, add, edit and delete is recorded with who did it, when, and from which IP address.
