# Setup guide

Setup and running instructions are now in **README.md** (quick start, settings, demo data, troubleshooting).

Short version for Windows with XAMPP:

1. Start MySQL in the XAMPP Control Panel.
2. Double click `setup.bat` once.
3. Double click `start.bat` whenever you want to run the system.

Admin panel: http://localhost:5000/admin/login.html (admin@campusstationery.com / Admin@123)
